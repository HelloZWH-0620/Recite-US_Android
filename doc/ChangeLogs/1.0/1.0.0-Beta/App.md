# 1.0.0-Beta

背书哇 v1.0.0 Beta

这是背书哇的首个公开测试版本。在此版本中，我们实现了完整的文言文与古诗词背诵阅读体验，包括文章阅读、作者资料、实验性朗读等核心功能。

## 🚀 新增功能与优化

### 阅读

- 【文章】内置 60 篇必背篇目（文言文 20 篇 + 古诗词 40 篇），列表按文言文 / 古诗词分组显示篇名与作者
- 【文章】顶部居中文字 Tab（文章 / 作者）切换，选中态主题色下划线
- 【文章】搜索框实时过滤篇目与作者，输入即出搜索建议，点击直达详情
- 【正文】主标题居中、作者名右对齐按钮，点击进入作者资料
- 【正文】按开关插入译文卡片、注释卡片（灰底白字），开启注释时正文对应词句自动变色高亮（浅色蓝 / 深色金黄）
- 【正文】文言文逐段首行缩进，词、曲仅首行缩进，普通诗歌不缩进
- 【正文】底部居中操作栏：注释 / 朗读 / 翻译，启用态为淡金底 + 金色文字

### 作者

- 【作者页】朝代导航（先秦 / 汉 / 魏晋南北朝 / 唐 / 五代 / 宋 / 元 / 明 / 清）与作者列表二级联动，点选定位、滚动高亮
- 【作者详情】内嵌 WebView + 自研 Markdown 渲染器，支持深色模式跟随系统
- 【作者详情】作者资料自动抓取自古诗文网并缓存到本地，支持复制链接 / 系统浏览器打开 / 分享

### 我的

- 【我的】清除缓存：删除已缓存的作者资料，Material AlertDialog 二次确认
- 【我的】设置：实验性功能开关（本地音频朗读、横屏旋转）、关于弹窗
- 【关于】软件信息、作者、共创作者、鸣谢、录音资源、正文资源与源代码地址

### 实验性功能

- 【朗读】播放内置朗读音频（人民教育出版社录音资源），由系统媒体中心 / 通知栏控制播放与暂停，播完单篇自动停止
- 【横屏】开启后允许竖屏旋转为横屏，关闭时锁定竖屏

### 体验

- 【导航】预测性返回手势跟手动画，与 Android 16 系统导航手势同步，逐级返回并完整保留滚动位置
- 【界面】Material 3 主题、系统字体、深色模式与原生触控反馈
- 【图标】应用图标适配全部分辨率密度
