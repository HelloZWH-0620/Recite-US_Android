# 1.6.4

背书哇 1.6.4

本次更新重做了朗读能力，支持系统 TTS、Edge 在线朗读与内置录音三种音源，并让媒体卡片逐句同步朗读内容；同时新增检查更新与截图纠错，补齐多篇朗读资源。

## 🚀 新增功能与优化

### 朗读

- 【朗读】新增系统 TTS / Edge 在线朗读 / 内置录音三种音源，可在「我的 → 朗读音源」中随时切换，默认使用系统 TTS
- 【朗读】TTS 模式按句切分正文逐句朗读，通知与锁屏媒体卡片同步展示当前句子
- 【朗读】TTS 模式在展开的工具栏中显示「第 i/n 句」进度，内置录音仍显示时间进度条并支持拖动
- 【朗读】选择内置录音但篇目暂无录音时，自动改用 Edge 在线朗读，不再提示「正在开发中」
- 【朗读】保留后台播放、熄屏播放、单曲循环与系统媒体卡片控制

### 我的与反馈

- 【我的】新增「检查更新」，点击后通过系统默认应用跳转 GitHub Releases 页面
- 【我的】新增「截图纠错」，默认开启；在任意页面截图后弹出 mochi 提示，点击即可复制 QQ 群号 950739151 并跳转 QQ 交流群
- 【我的】朗读音源选择沿用 mochi iOS 弹出式菜单，选项附带当前音源说明

### 资源与构建

- 【资源】新增《论语》十二章、屈原列传、答司马谏议书、阿房宫赋、谏太宗十思疏、项脊轩志、子路、琵琶行并序等篇目的内置录音
- 【构建】统一 1.6.1122 及之后各版本的签名密钥，修复覆盖安装时出现的签名不一致问题
- 【构建】签名口令改为从本地 `keystore/keystore.properties` 读取，仓库不再包含任何密钥信息
- 【构建】版本号更新为 1.6.4

## 🐛 Bug 修复

- 【朗读】修复部分篇目点击朗读无反应的问题
- 【朗读】修复暂停后重新播放丢失当前句的问题
- 【朗读】修复 Edge 在线朗读因接口鉴权升级导致的播放失败
- 【关于】版本号展示去掉多余的 `v` 前缀
